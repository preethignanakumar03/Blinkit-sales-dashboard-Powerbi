🛒 **Blinkit Grocery Sales Dashboard – Power BI Project**

This project focuses on building an interactive Power BI dashboard to analyze Blinkit grocery sales data and generate actionable business insights. The dashboard provides a comprehensive view of sales performance, product trends, customer behavior, and outlet efficiency.

The goal of this project is to simulate a real-world retail analytics scenario, where raw sales data is transformed into meaningful visual insights to support data-driven decision-making.

📊 **Project Overview**

The Blinkit Grocery Sales Dashboard is an end-to-end business intelligence project developed using Power BI to analyze retail sales performance and customer purchasing behavior.

This dashboard transforms raw transactional data into interactive visual insights, allowing users to explore:

  - Sales trends across product categories:

  - Outlet performance analysis

  - Customer rating insights

  - Item-level sales performance

  - Inventory and product distribution patterns

The project demonstrates strong capabilities in data visualization, business analytics, and dashboard development, reflecting real-world industry practices.

📊 **Key Performance Indicators (KPIs)**

       🛒 Total Sales: Overall revenue generated from all items

       📦 Total Items Sold: Total number of products sold

       💰 Average Sales: Average revenue per item

       ⭐ Average Rating: Overall customer satisfaction score

       🏪 Total Outlets: Number of outlets analyzed

       📊 Sales by Item Type: Revenue distribution across categories

       🏬 Sales by Outlet Size: Performance comparison by outlet size

       📍 Sales by Outlet Location: Tier-wise sales comparison

       🏪 Sales by Outlet Type: Grocery vs Supermarket performance

       📅 Outlet Establishment Trend: Sales performance over time

Using Power BI, the dashboard highlights key business metrics such as total sales, average sales, product category performance, outlet trends, and customer ratings, enabling stakeholders to quickly understand performance patterns and identify growth opportunities
